# Open GenOffice v0.4.0

This is the first public binary release of Open GenOffice, an independent
Apache-2.0 derivative of GenOffice.

## Downloads

- `OpenGenOffice-0.4.0-arm64.dmg` — signed and notarized macOS installer for
  Apple silicon Macs.
- `OpenGenOffice-0.4.0-arm64.zip` — signed and notarized macOS application
  archive for Apple silicon Macs.
- `OpenGenOfficeSetup-v0.4.0-x64.exe` — Windows x64 installer.
- `SHA256SUMS.txt` — SHA-256 checksums for all release binaries.

The macOS application is signed by `Developer ID Application: Mythic Source
LLC (6C326Q2WAH)` and notarized by Apple.

Intel Macs are not supported by this release. The Windows installer is not
code-signed, so Microsoft Defender SmartScreen may show an unknown-publisher
warning on first launch.

## Highlights

- Keeps the built-in Genspark provider available.
- Adds first-class OpenRouter, Anthropic, and OpenAI provider configuration.
- Encrypts user-supplied API keys through Electron `safeStorage`.
- Adds suite-wide defaults and sticky per-document provider/model routing.
- Introduces independent Open GenOffice application identity, branding, and
  update configuration.
